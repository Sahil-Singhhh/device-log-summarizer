## Section 3 — AI-Assisted Chart Workflow

### Initial Prompt

> "Generate a Python script called chart.py that reads output.json produced by
> a device telemetry summarizer. It should use Matplotlib to create a bar chart
> of average temperature per device. Include a title, x-axis label (Device ID),
> y-axis label (Average Temperature in Celsius), value labels on each bar,
> a subtle horizontal grid, and save the chart as temperature_chart.png.
> Handle missing or empty JSON gracefully. Close the figure after saving."

---

### Initial Output Review

The first implementation generated by the AI produced a chart with correct
structure — title, axis labels, value annotations, and grid were all present.

**Real bug observed:** The x-axis tick labels (device IDs) were **not rotated**.
When running the chart against the actual `output.json` (which contained five
devices: DEV_A, DEV_C, DEV_D, DEV_F, plus any additional), the horizontal
device-ID labels overlapped and became partially unreadable when the figure
was rendered at the default DPI.

**Why it mattered:** A reviewer opening `temperature_chart.png` would see
illegible x-axis labels, making the chart fail its core purpose of legibly
comparing devices.

**Evidence in initial code:** The initial `generate_chart()` function called
`plt.tight_layout()` and `plt.savefig()` but had no `plt.xticks(rotation=…)`
call. The comment in the code reads:

```python
# BUG (initial version): no rotation on x-tick labels.
# With many devices the labels overlap and become unreadable.
# plt.xticks(rotation=45, ha="right")   ← not present in initial version
```

---

### Follow-up Prompt

> "The x-axis device labels overlap when there are five or more devices. Add
> `plt.xticks(rotation=45, ha='right')` after setting the axis labels so the
> tick labels are rotated 45 degrees and right-aligned. Rerun and confirm the
> chart is legible."

---

### Final Changes

The corrected `generate_chart()` function in `chart.py` adds:

```python
plt.xticks(rotation=45, ha="right")
```

immediately before `plt.tight_layout()`. The `tight_layout()` call then
accounts for the rotated labels and prevents them from being clipped at the
bottom of the figure.

**Verification:** After the fix, running `python chart.py` against the actual
`output.json` produced a `temperature_chart.png` where all device IDs are
clearly legible, angled at 45 degrees, without overlapping.
